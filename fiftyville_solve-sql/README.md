The following program uses various tables in a .db file ( Snapshot of ER diagram attached ) to solve and find out the criminal of the given crime:

The CS50 Duck has been stolen! The town of Fiftyville has called upon you to solve the mystery of the stolen duck.
Authorities believe that the thief stole the duck and then, shortly afterwards, took a flight out of town with the help of an accomplice. 

Given data: The theft took place on July 28, 2025 and that it took place on Humphrey Street

log.sql contains all the SQL queries used (dialect = sqlite) in finding the criminal with appropriate comments.
The database-post (Snapshot of ER diagram attached) contains a table created after solving the crime about the criminal and their details fetched from database-pre.db/ TABLE people.
