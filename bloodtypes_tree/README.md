The following program creates a family for specified number of generations (defined as a const in the code), and outputs a family tree containing the respective blood types for each member.

Each member has 2 alleles and 2 parents assigned to them.
The oldest members in the tree (those with no parents assigned to them) are randomly assigned alleles for blood types ('A', 'B', 'O').
Each child of a member (if it exists) is randomly assigned alleles, by choosing one from either parents.
